**🕒 13:05–14:05**  
**🏷️ Labels**: Financial Analysis, Data Visualization, AAPL, MSFT, Candlestick Charts  
**📂 Project**: Business  



### Session Goal
The session aimed to develop and enhance financial analysis tools for evaluating the performance of Apple (AAPL) and Microsoft (MSFT) stocks using quantitative methods and [[data [[visualization]]]] techniques.

### Key Activities
- **Quantitative Problem Solving Presentation**: Introduced quantitative approaches in capital management using Bayesian reasoning, game theory, and pairs trading.
- **Correlation Analysis**: Explored correlation frameworks for market benchmarks over various time windows, aiding trading strategies and portfolio management.
- **Relative Performance Analysis**: Analyzed AAPL vs. MSFT using rolling 90-day returns, emphasizing pairs trading strategies.
- **yfinance Library Usage**: Provided instructions for installing and using the `yfinance` library for financial [[data analysis]].
- **Candlestick Chart Implementation**: Developed scripts using `mplfinance` to create weekly candlestick charts for AAPL and MSFT, focusing on data fetching, processing, and [[visualization]] aesthetics.

### Achievements
- Successfully implemented and customized candlestick charts for AAPL and MSFT, incorporating annotations and consistent styling.
- Enhanced understanding of correlation analysis and its application in trading strategies.
