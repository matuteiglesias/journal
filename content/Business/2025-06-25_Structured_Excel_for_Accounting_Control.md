### Session Goal
The session aimed to design and implement a structured Excel file to facilitate accounting control, integrating data from various sources and automating processes.

### Key Activities

- Implemented methods for importing data from the web using Power Query and [[Python]].

- Created a 'Movimientos' sheet with concatenated D+/C+ rows and a 'Periodo' column for filtering or pivoting.

- Compiled financial records from 2022 to 2025 into a single Excel file for consolidated accounting.
