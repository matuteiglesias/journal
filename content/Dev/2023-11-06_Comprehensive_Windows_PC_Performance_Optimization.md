### Session Goal
The goal of this session was to diagnose and optimize the performance of Windows PCs, focusing on both software and hardware aspects.

### Key Activities
- **Diagnosing Performance Issues**: A systematic guide was followed to diagnose slow performance in Windows PCs, including hardware checks and software maintenance.
- **Hardware Diagnostics**: Steps were outlined to check hardware specifications using Command Prompt and PowerShell.
- **Performance Analysis**: Analyzed performance characteristics of systems with Intel Atom processors and eMMC storage.
- **[[Optimization]] Strategies**: Developed strategies for optimizing performance on low-power systems, including BIOS adjustments and software streamlining.
- **Windows Defender [[Optimization]]**: Provided strategies to manage resource usage by Windows Defender, including reprogramming scans and setting exclusions.
- **Disk Space Management**: Addressed discrepancies in application size versus disk usage and provided storage management steps.
- **Software Uninstallation Guidelines**: Offered guidelines for uninstalling unnecessary software to improve system performance.

### Achievements
- Developed a comprehensive approach to diagnosing and optimizing Windows PC performance.
- Identified potential bottlenecks in low-power systems and provided actionable [[optimization]] strategies.
- Enhanced understanding of Windows Defender's impact on system resources and how to mitigate it.
