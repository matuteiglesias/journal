## 📅 2024-08-13 — Session: Enhanced Spreadsheet Formula Techniques and Error Handling

**🕒 04:20–05:20**  
**🏷️ Labels**: Google Sheets, Excel, Formulas, Error Handling, Data Analysis  
**📂 Project**: Dev  



### Session Goal
The session aimed to explore and enhance skills in using spreadsheet formulas for various data manipulation tasks in Google Sheets and Excel.

### Key Activities
- **Google Sheets String Comparison**: Learned to use the `EXACT` function for string comparison and explored a case-insensitive alternative using the `IF` function.
- **[[Troubleshooting]] Formula Syntax**: Developed a step-by-step guide to troubleshoot formula syntax issues, focusing on the `EXACT` function.
- **Date Calculation in Google Sheets**: Created formulas using `IF`, `SEARCH`, and `DATE` functions to calculate dates based on text conditions.
- **Age Calculation in Excel**: Utilized `DATEDIF` and `TODAY()` functions to calculate age differences for specific past years.
- **[[Error Handling]] in Excel**: Implemented the `IFERROR` function with `SEARCH` to manage errors in formulas.
- **Combined Formulas for Age Calculation**: Developed a robust formula using `IF` and `IFERROR` to handle age calculation and errors.
- **Average Calculation in Google Sheets**: Formulated a method to calculate the average of non-null values using `ARRAYFORMULA`, `FILTER`, and `AVERAGE` functions.

### Achievements
- Successfully created and tested various formulas for string comparison, date calculations, and [[error handling]] in both Google Sheets and Excel.
- Enhanced [[troubleshooting]] skills for spreadsheet formula syntax.
