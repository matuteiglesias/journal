## 📅 2025-02-27 — Session: Optimized Storage and Managed Electoral Data

**🕒 20:25–21:05**  
**🏷️ Labels**: Storage Optimization, Data Management, Disk Cleanup, File Recovery, Cloud Storage  
**📂 Project**: Dev  



### Session Goal
The session aimed to optimize storage space and manage electoral data efficiently.

### Key Activities
1. **Storage [[Optimization]]**: Implemented steps to identify and reduce storage space usage by cleaning up large directories and files. This included commands for deleting, compressing, and archiving data.
2. **Electoral [[Data Management]]**: Reorganized the `electoral_v1` directory by merging files, restructuring folders, and cleaning up redundant data to enhance accessibility and efficiency.
3. **Disk Cleanup**: Conducted disk cleanup by addressing large directories, hidden trash files, and potential corrupted files. Commands for force deletion, file system checks, compression of backups, and deduplication of data were utilized.
4. **File System Management**: Executed a systematic approach to forcefully delete a corrupted file on an external drive, including checking the file system for errors and using alternative deletion commands.
5. **File Recovery**: Followed a step-by-step guide for dealing with severely corrupted files, including processes to find and terminate, force unmount, and run file system checks.
6. **Cloud Storage Management**: Uploaded the Census 2010 dataset to Google Cloud Storage, involving installation, authentication, folder creation, file upload, verification, and making files public.

### Achievements
- Successfully optimized storage space and organized the electoral data repository.
- Completed disk cleanup and managed corrupted files.
- Uploaded Census data to Google Cloud Storage efficiently.
