**Session Goal:**

- Clarified the correct usage of `hreflang` in HTML versus `hrefLang` in React to ensure proper JSX implementation.
- Conducted an [[SEO]] analysis of `sitemap.xml` and `robots.txt` files, identifying areas for improvement.
- Provided a guide for improving web performance and accessibility using Core Web Vitals, and set up Google Analytics 4 and Google Tag Manager.
- Implemented Google Tag Manager and GA4 for tracking user behavior and performance, ensuring compliance with GDPR through a cookie consent banner.

**Achievements:**
