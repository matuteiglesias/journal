## 📅 2025-07-14 — Session: Developed Job Data Extraction and Text Extraction Alternatives

**🕒 01:25–01:35**  
**🏷️ Labels**: Job Extraction, Web Scraping, Streamlit, Selenium, Text Extraction  
**📂 Project**: Dev  
**⭐ Priority**: MEDIUM  


### Session Goal
The session aimed to explore strategies for extracting structured job information from HTML job pages and to discuss alternatives for text extraction using [[Streamlit]] apps.

### Key Activities
- **Job Data Extraction**: Developed a strategy for extracting structured job information from HTML job pages using [[JSON]]-LD data and minimal HTML snippet extraction. This involved outlining methods to discard unnecessary frontend data and implementing examples using BeautifulSoup.
- **[[Streamlit]] App Limitations**: Explored the limitations of [[Streamlit]] apps in accessing client-side resources. Discussed three alternatives for text extraction from web pages, including using browser extensions, local applications with Selenium, and client-side iframe techniques.

### Achievements
- Successfully outlined and implemented strategies for job data extraction using [[JSON]]-LD and HTML snippets.
- Identified and discussed viable alternatives for text extraction in the context of [[Streamlit]] app limitations.

### Pending Tasks
- Further testing and refinement of the proposed job data extraction strategies.
- Implementation and evaluation of the proposed text extraction alternatives in real-world scenarios.
