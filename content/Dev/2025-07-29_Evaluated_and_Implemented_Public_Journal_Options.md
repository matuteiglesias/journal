## 📅 2025-07-29 — Session: Evaluated and Implemented Public Journal Options

**🕒 22:10–23:20**  
**🏷️ Labels**: Obsidian, Docusaurus, Quartz, Digital Garden, Publishing  
**📂 Project**: Dev  
**⭐ Priority**: MEDIUM  


### Session Goal
The goal of this session was to explore and evaluate different options for creating a publicly accessible journal using tools like [[Docusaurus]], Obsidian, and Quartz. The session also aimed to identify effective methods for publishing Obsidian notes online.

### Key Activities
- **Evaluation of Tools**: Compared [[Docusaurus]] and Obsidian with Quartz for public journaling, focusing on aesthetics and user experience.
- **Publishing Alternatives**: Explored free tools and methods for converting Obsidian vaults into public sites, maintaining features like graph view and backlinks.
- **Implementation Guide**: Developed a step-by-step guide to publish an Obsidian vault online using the Digital Garden Plugin with GitHub and Vercel.
- **Application for TTRPG and Journaling**: Discussed the use of Obsidian for TTRPG worldbuilding and personal journaling, leveraging its graph view and automation features.

### Achievements
- Quartz was recommended for its aesthetic and immersive user experience.
- A comprehensive guide for publishing Obsidian vaults online was created.
- Identified multiple free tools for Obsidian note publishing.
- Explored the application of Obsidian for both TTRPG and personal journaling.

### Pending Tasks
- Further exploration of customization options within Quartz for enhanced user experience.
- Testing the implementation of the Digital Garden Plugin setup with a live Obsidian vault.
